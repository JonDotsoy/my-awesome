## 🤖 IA e Automação

**Agentes e desenvolvimento assistido por IA**

- [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD) - Framework multi-agentes de código aberto com 21+ agentes especializados (PM, Architect, Developer, QA) e fluxos de trabalho guiados para todo o ciclo de vida do desenvolvimento.
- [GitHub Spec Kit](https://github.com/github/spec-kit) - Toolkit para desenvolvimento guiado por especificações (Spec-Driven Development), pensado para agentes de codificação IA como Copilot ou Claude.
- [OpenSpec](https://openspec.dev/) - Toolkit SDD que estrutura o desenvolvimento a partir de especificações em Markdown antes da implementação, projetado para assistentes de IA.
- [Skills.sh](https://skills.sh/) - Gerenciador de pacotes de habilidades modulares para agentes de IA (similar ao npm), para estender capacidades como edição de vídeo ou interação com APIs.
- [Pencil.dev](https://www.pencil.dev/) - Canvas vetorial infinito integrado ao editor de código que converte designs em HTML/CSS/React via MCP.
- [Zro](https://zro.moonmath.ai/) - Endpoint de inferência privado da MoonMath.ai com modelos open-weight para agentes de codificação, infraestrutura na UE e compatibilidade de API OpenAI/Anthropic.

**Comparadores de LLMs**

- [Arena.ai Leaderboard](https://arena.ai/leaderboard) - Ranking público impulsionado por votos da comunidade que compara modelos frontier em texto, código e visão.
- [ARC Prize Leaderboard](https://arcprize.org/leaderboard) - Benchmark oficial ARC-AGI que mede inteligência fluida e capacidade de generalização dos modelos.
- [OpenAI Compare Models](https://developers.openai.com/api/docs/models/compare) - Comparação oficial lado a lado de todos os modelos da API da OpenAI (preço, contexto, capacidades).
- [Artificial Analysis](https://artificialanalysis.ai/) - Benchmarks independentes de 100+ modelos com métricas de inteligência, velocidade, latência e custo.
- [LLM Price](https://llm-price.com/) - Calculadora de preços por token para comparar o custo dos principais LLMs entre provedores.
- [isbetter.ai](https://isbetter.ai/) - Compara a resposta, código, pré-visualização, velocidade e custo de vários modelos de IA para o mesmo prompt.

**Automação de processos**

- [Make.com](https://www.make.com/) - Plataforma de automação visual com muitas integrações, mais simples de entender que o n8n.
- [n8n](https://n8n.io/) - Plataforma de automação de fluxos de trabalho de código aberto via interface visual.
- [Apache Airflow](https://airflow.apache.org/) - Plataforma para programar e monitorar fluxos de trabalho como DAGs, ideal para pipelines de dados.
- [Spring Batch](https://spring.io/projects/spring-batch) - Framework de processamento por lotes para Java dentro do ecossistema Spring.

## 💻 Desenvolvimento Web

**Componentes UI e React**

- [Magic UI](https://magicui.design/) - Mais de 150 componentes animados copy-paste para React/Tailwind, com ênfase em motion design.
- [ReUI](https://reui.io/) - Componentes React copy-paste construídos com Tailwind CSS, Radix UI e TypeScript, sem dependências.
- [Blocks](https://blocks.so/) - Coleção de componentes visuais copy-paste para shadcn/ui.
- [mapcn](https://mapcn.vercel.app/) - Componentes de mapas interativos copy-paste para shadcn/ui, baseados em Leaflet.
- [Zustand](https://github.com/pmndrs/zustand) - Biblioteca minimalista de estado global para React baseada em hooks, sem providers ou reducers.
- [NanoStores](https://github.com/nanostores/nanostores) - Gerenciador de estado minimalista (~286 bytes) para React, Vue, Svelte e JS puro.

**Gráficos e diagramação**

- [TypeGPU](https://docs.swmansion.com/TypeGPU/) - Biblioteca TypeScript type-safe sobre WebGPU para gráficos 3D e computação GPU no navegador.
- [Three.js](https://threejs.org/) - A biblioteca JS mais popular para gráficos e visualizações 3D interativas com WebGL.
- [Babylon.js](https://www.babylonjs.com/) - Motor de gráficos 3D com suporte a PBR, física integrada e capacidades AR/VR via WebXR.
- [Mermaid](https://mermaid.js.org/) - Cria diagramas e visualizações a partir de texto em Markdown.
- [Excalidraw](https://excalidraw.com/) - Quadro branco virtual colaborativo com aparência desenhada à mão, ideal para brainstorming.
- [MakeGraph](https://makegraph.app/es) - Ferramenta gratuita para criar gráficos e diagramas (barras, linhas, radar, mapas de calor) sem cadastro.

**Testing e APIs**

- [Playwright](https://playwright.dev/) - Framework da Microsoft para automação de navegadores e testing end-to-end cross-browser.
- [Stagehand](https://www.stagehand.dev/) - Framework de automação de navegadores que combina código e linguagem natural, pensado para agentes IA.
- [HTTPie](https://httpie.io/) - Cliente HTTP moderno com sintaxe intuitiva e saída formatada, alternativa simples e gratuita.
- [Postman](https://www.postman.com/) - Plataforma integral para desenvolvimento, teste, documentação e colaboração de APIs.
- [Bruno](https://www.usebruno.com/) - Cliente de API open-source e offline-first, alternativa ao Postman com coleções armazenadas como arquivos de texto.

## 🖥️ Infraestrutura e Código

- [nginx](https://nginx.org/) - Servidor web de alto desempenho, proxy reverso e balanceador de carga.
- [Caddy](https://caddyserver.com/) - Servidor web e proxy reverso com HTTPS automático, alternativa moderna ao nginx.
- [Cloudflare Workers](https://workers.cloudflare.com/) - Plataforma serverless para executar JS no edge da Cloudflare com baixa latência global.
- [IP Guide](https://ip.guide/) - Consulta gratuita de informações detalhadas sobre IPs, redes e ASN, com API incluída.
- [Portless](https://github.com/vercel-labs/portless) - Substitui portas por URLs estáveis em `.localhost` para desenvolvimento local.
- [GitHub](https://github.com/) - Plataforma de hospedagem de código com repos, PRs, issues e GitHub Actions.
- [Codeberg](https://codeberg.org/) - Hospedagem de código livre e sem fins lucrativos baseada em Forgejo, com foco em privacidade.
- [GitLab](https://gitlab.com/) - Plataforma DevOps tudo-em-um com Git, CI/CD, issues e registros de contêineres.
