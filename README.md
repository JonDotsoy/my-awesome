## 🤖 IA y Automatización

**Agentes y desarrollo asistido por IA**

- [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD) - Framework multi-agentes de código abierto con 21+ agentes especializados (PM, Architect, Developer, QA) y flujos de trabajo guiados para todo el ciclo de vida del desarrollo.
- [GitHub Spec Kit](https://github.com/github/spec-kit) - Toolkit para desarrollo guiado por especificaciones (Spec-Driven Development), ideal para trabajar con agentes de codificación IA como Copilot o Claude.
- [OpenSpec](https://openspec.dev/) - Toolkit SDD que estructura el desarrollo a partir de especificaciones en Markdown antes de implementar, pensado para asistentes de IA.
- [Skills.sh](https://skills.sh/) - Gestor de paquetes de habilidades modulares para agentes de IA (similar a npm), para extender capacidades como edición de video o interacción con APIs.
- [Pencil.dev](https://www.pencil.dev/) - Canvas vectorial infinito integrado en el editor de código que convierte diseños en HTML/CSS/React vía MCP.
- [Zro](https://zro.moonmath.ai/) - Endpoint de inferencia privado de MoonMath.ai con modelos open-weight para agentes de codificación, infraestructura en la UE y compatibilidad de API OpenAI/Anthropic.

**Comparadores de LLMs**

- [Arena.ai Leaderboard](https://arena.ai/leaderboard) - Ranking público impulsado por votos de la comunidad que compara modelos frontier en texto, código y visión.
- [ARC Prize Leaderboard](https://arcprize.org/leaderboard) - Benchmark oficial ARC-AGI que mide inteligencia fluida y capacidad de generalización de los modelos.
- [OpenAI Compare Models](https://developers.openai.com/api/docs/models/compare) - Comparación oficial lado a lado de todos los modelos de la API de OpenAI (precio, contexto, capacidades).
- [Artificial Analysis](https://artificialanalysis.ai/) - Benchmarks independientes de 100+ modelos con métricas de inteligencia, velocidad, latencia y costo.
- [LLM Price](https://llm-price.com/) - Calculadora de precios por token para comparar el costo de los principales LLMs entre proveedores.

**Automatización de procesos**

- [Make.com](https://www.make.com/) - Plataforma de automatización visual con muchas integraciones, más simple de entender que n8n.
- [n8n](https://n8n.io/) - Plataforma de automatización de flujos de trabajo de código abierto mediante interfaz visual.
- [Apache Airflow](https://airflow.apache.org/) - Plataforma para programar y monitorear flujos de trabajo como DAGs, ideal para pipelines de datos.
- [Spring Batch](https://spring.io/projects/spring-batch) - Framework de procesamiento por lotes para Java dentro del ecosistema Spring.

## 💻 Desarrollo Web

**Componentes UI y React**

- [Magic UI](https://magicui.design/) - Más de 150 componentes animados copy-paste para React/Tailwind, con énfasis en motion design.
- [ReUI](https://reui.io/) - Componentes React copy-paste construidos con Tailwind CSS, Radix UI y TypeScript, sin dependencias.
- [Blocks](https://blocks.so/) - Colección de componentes visuales copy-paste para shadcn/ui.
- [mapcn](https://mapcn.vercel.app/) - Componentes de mapas interactivos copy-paste para shadcn/ui, basados en Leaflet.
- [Zustand](https://github.com/pmndrs/zustand) - Librería minimalista de estado global para React basada en hooks, sin providers ni reducers.
- [NanoStores](https://github.com/nanostores/nanostores) - Gestor de estado minimalista (~286 bytes) para React, Vue, Svelte y JS vanilla.

**Gráficos y diagramación**

- [TypeGPU](https://docs.swmansion.com/TypeGPU/) - Librería TypeScript type-safe sobre WebGPU para gráficos 3D y computación GPU en el navegador.
- [Three.js](https://threejs.org/) - Librería JS más popular para gráficos y visualizaciones 3D interactivas con WebGL.
- [Babylon.js](https://www.babylonjs.com/) - Motor de gráficos 3D con soporte PBR, física integrada y capacidades AR/VR vía WebXR.
- [Mermaid](https://mermaid.js.org/) - Crea diagramas y visualizaciones a partir de texto en Markdown.
- [Excalidraw](https://excalidraw.com/) - Pizarra virtual colaborativa con apariencia dibujada a mano, ideal para brainstorming.
- [MakeGraph](https://makegraph.app/es) - Herramienta gratuita para crear gráficos y diagramas (barras, líneas, radar, mapas de calor) sin registro.

**Testing y APIs**

- [Playwright](https://playwright.dev/) - Framework de Microsoft para automatización de navegadores y testing end-to-end cross-browser.
- [Stagehand](https://www.stagehand.dev/) - Framework de automatización de navegadores que combina código y lenguaje natural, pensado para agentes IA.
- [HTTPie](https://httpie.io/) - Cliente HTTP moderno con sintaxis intuitiva y salida formateada, alternativa simple y gratuita.
- [Postman](https://www.postman.com/) - Plataforma integral para desarrollo, testing, documentación y colaboración de APIs.
- [Bruno](https://www.usebruno.com/) - Cliente de API open-source y offline-first, alternativa a Postman con colecciones almacenadas como archivos de texto.

## 🖥️ Infraestructura y Código

- [nginx](https://nginx.org/) - Servidor web de alto rendimiento, proxy reverso y balanceador de carga.
- [Caddy](https://caddyserver.com/) - Servidor web y proxy reverso con HTTPS automático, alternativa moderna a nginx.
- [Cloudflare Workers](https://workers.cloudflare.com/) - Plataforma serverless para ejecutar JS en el edge de Cloudflare con baja latencia global.
- [IP Guide](https://ip.guide/) - Consulta gratuita de información detallada sobre IPs, redes y ASN, con API incluida.
- [Portless](https://github.com/vercel-labs/portless) - Reemplaza puertos por URLs estables en `.localhost` para desarrollo local.
- [GitHub](https://github.com/) - Plataforma de alojamiento de código con repos, PRs, issues y GitHub Actions.
- [Codeberg](https://codeberg.org/) - Alojamiento de código libre y sin fines de lucro basado en Forgejo, con foco en privacidad.
- [GitLab](https://gitlab.com/) - Plataforma DevOps todo-en-uno con Git, CI/CD, issues y registros de contenedores.
